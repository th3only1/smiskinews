# Newsletter Website Template

A modern, responsive newsletter website template with subscription capabilities.

## Features

- 📧 Email subscription form
- 📱 Fully responsive design
- 🎨 Modern gradient styling
- ✨ Smooth scrolling navigation
- 📰 Newsletter archive section
- 💬 Contact form
- 🔗 Social media links

## Files

- `index.html` - Main HTML structure
- `styles.css` - All styling and responsive design
- `script.js` - Interactive functionality (forms, smooth scrolling)

## Usage

1. Clone or download this repository
2. Open `index.html` in your web browser
3. Customize the content, colors, and information to match your newsletter
4. Connect the forms to a backend service for actual email handling

## Customization

### Change Colors
Edit the gradient colors in `styles.css`:
```css
background: linear-gradient(135deg, #667eea 0%, #764ba2 100%);
```

### Update Newsletter Name
Change "My Newsletter" in `index.html` to your newsletter name.

### Connect Forms
Replace the form handlers in `script.js` with actual backend API calls to:
- Store email subscriptions
- Send contact form messages
